# Hardware-Box v1.2.0 source bundle

The numbered binary fragments in this directory are ordered parts of the official `hardware-box-source.tar.xz` release archive. Run `python restore_core.py` from the repository root to reassemble and extract them.

Expected SHA-256:

```
9b593b005ca911ec8e49f91dd229eafde3ad6ad16bb05a5f777d50a88767b7ad
```

The restore utility rejects unsafe paths and verifies the digest before extracting.
