# Agent Instructions — Hardware-Box

Read README.md, CONTRIBUTING.md, FEATURE_UPGRADE_PLAN.md and ACTIVITY_LOG.md before making changes.

1. Inspect the relevant code, tests and open PRs first.
2. State the bounded task, expected files, risks and validation plan.
3. Work on a dedicated branch; keep diffs minimal.
4. Add deterministic tests for expected, boundary and failure behavior.
5. Run the documented checks and report exact commands/results.
6. Update docs and append a truthful activity-log entry.
7. Open a PR; do not merge, deploy, publish packages or change repository settings.

Never invent metrics, test outcomes or data provenance. Do not introduce secrets, private information or unlicensed datasets. Stop and request human review for destructive actions, ambiguous scope or safety-sensitive claims.
